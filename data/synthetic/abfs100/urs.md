# User Requirements Specification

System: ABFS-100 Automated Bottle Filling System

Document ID: URS-ABFS-100

## User Requirements

### URS-001 — User Authentication

The system shall require users to authenticate before accessing
GxP-relevant system functions.

### URS-002 — Role-Based Access

The system shall restrict system functions according to the user's
assigned role.

### URS-003 — Recipe Selection

The system shall allow Operators to select only approved production
recipes.

### URS-004 — Bottle Detection

The system shall detect the presence of a bottle before initiating
the filling operation.

### URS-005 — Tablet Count Verification

The system shall verify that the required number of tablets has been
dispensed into each bottle.

### URS-006 — Reject Function

The system shall automatically reject a bottle when the required
tablet count is not achieved.

### URS-007 — Critical Alarms

The system shall generate an alarm when a critical equipment or
process failure is detected.

### URS-008 — Audit Trail

The system shall record GxP-relevant user actions and configuration
changes in an electronic audit trail.

### URS-009 — Batch Records

The system shall electronically record relevant production
information for each processed batch.

### URS-010 — Data Backup

The system shall support backup and restoration of GxP-relevant
electronic records.

### URS-011 — Time Stamps

Electronic records shall include a system-generated date and time.

### URS-012 — System Recovery

Following an unexpected system interruption, the system shall recover
without unauthorized loss or modification of stored GxP data.
